# Tanmayi R S — Technical Writing Portfolio

A portfolio website and three runnable sample projects demonstrating technical communication, developer documentation, and documentation automation.

## Website

The static portfolio home page is `index.html`.

**GitHub Pages URL (after Pages is enabled):**  
https://tanmayi1996.github.io/tanmayi-portfolio/

To activate hosting, open **Settings → Pages** in this repository and set **Build and deployment → Source** to **GitHub Actions**. The workflow is already committed at `.github/workflows/pages.yml`.

## Projects

- [AI Release Notes Generator](./ai-release-notes-generator/) — creates grouped Markdown release notes from structured JSON change records.
- [API Documentation Toolkit](./api-documentation-toolkit/) — includes a fictional OpenAPI 3.1 contract, reader-facing API guide, and structural checks.
- [Documentation Quality Checker](./documentation-quality-checker/) — scans Markdown for broken relative links, placeholders, missing headings, and long prose lines.

All sample product names, API endpoints, and data are fictional. Review generated content before publication.

## Local preview

Open `index.html` in a modern browser.

Each project folder contains its own README with run and test commands.
